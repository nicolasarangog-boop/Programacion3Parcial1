## Descripción

Este proyecto implementa un sistema para la gestión y liquidación de entregas de leche realizadas por diferentes productores en un centro de acopio.

El sistema permite validar las entregas, calcular el valor correspondiente a cada productor, aplicar bonificaciones y descuentos, y generar diferentes reportes sobre la operación del centro de acopio.
